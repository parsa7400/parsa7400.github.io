## ⚡ درباره پروژه | Overview

پورتفولیوی شخصی **`parsa7400`** یک سامانه مدرن، سبک و سریع برای نمایش مهارت‌ها، پروژه‌ها و فعالیت‌های برنامه‌نویسی است.

این پروژه بدون استفاده از فریم‌ورک‌های سنگین مانند React و Vue و با معماری **Pure Vanilla JavaScript** توسعه داده شده است.

یکی از مهم‌ترین قابلیت‌های این پروژه، وجود یک **پنل مدیریت داخلی (CMS)** است که امکان مدیریت اطلاعات پورتفولیو را از طریق رابط کاربری و اتصال به **GitHub Contents API** فراهم می‌کند.

# 💻 آموزش نصب روی کامپیوتر | Installation Guide

<p align="center">
  <img src="https://media.giphy.com/media/f3iwJFOVOwuy7K6FFw/giphy.gif" width="80%">
</p>

می‌خواهید این پروژه را روی کامپیوتر شخصی خود اجرا کنید؟

با انجام مراحل زیر می‌توانید سایت را به‌صورت محلی اجرا کرده و تغییرات دلخواه خود را اعمال کنید.

### 📋 مرحله اول: پیش‌نیازها

ابتدا نرم‌افزارهای زیر را نصب کنید:

| نرم‌افزار | کاربرد | لینک دانلود |
|:---|:---|:---|
| Git | دریافت پروژه | [Download](https://git-scm.com/downloads) |
| VS Code | ویرایش کد | [Download](https://code.visualstudio.com/) |
| Google Chrome | اجرای سایت | [Download](https://www.google.com/chrome/) |
| Python | اجرای سرور محلی (اختیاری) | [Download](https://www.python.org/downloads/) |

### 📥 مرحله دوم: دریافت پروژه

CMD یا PowerShell را باز کنید و دستور زیر را وارد کنید:

```bash
git clone https://github.com/parsa7400/parsa7400.github.io.git
```

سپس وارد پوشه پروژه شوید:

```bash
cd parsa7400.github.io
```

### 🧩 مرحله سوم: باز کردن پروژه در VS Code

دستور زیر را اجرا کنید:

```bash
code .
```

اگر دستور بالا کار نکرد:

1. VS Code را باز کنید.
2. روی File کلیک کنید.
3. گزینه Open Folder را انتخاب کنید.
4. پوشه `parsa7400.github.io` را باز کنید.

### 🚀 مرحله چهارم: اجرای سایت

دو روش برای اجرای پروژه وجود دارد.

**روش اول: استفاده از Live Server (پیشنهادی)**

1. وارد VS Code شوید.
2. قسمت Extensions را باز کنید.
3. عبارت `Live Server` را جستجو کنید.
4. افزونه را نصب کنید.
5. فایل `index.html` را باز کنید.
6. روی صفحه کلیک راست کنید.
7. گزینه Open with Live Server را بزنید.

سایت شما معمولاً در آدرس زیر اجرا می‌شود:

```text
http://127.0.0.1:5500
```

**روش دوم: استفاده از Python**

ترمینال VS Code را باز کرده و دستور زیر را اجرا کنید:

```bash
python -m http.server 8000
```

سپس وارد مرورگر شوید:

```text
http://localhost:8000
```

برای متوقف کردن سرور کلیدهای `CTRL + C` را فشار دهید.

### 🎨 مرحله پنجم: شخصی‌سازی سایت

برای تغییر اطلاعات پورتفولیو فایل زیر را باز کنید:

```text
portfolio.json
```

در این فایل، مطابق ساختار موجود، می‌توانید موارد زیر را تغییر دهید:

- 👤 اطلاعات شخصی
- 📝 متن درباره من
- 💻 مهارت‌های برنامه‌نویسی
- 🚀 پروژه‌ها
- 🔗 لینک شبکه‌های اجتماعی
- 🌐 اطلاعات زبان فارسی و انگلیسی

**نکته:** ساختار JSON را حفظ کنید؛ اشتباه در کاما، کوتیشن یا براکت ممکن است باعث بارگذاری نشدن اطلاعات شود.

### 🌍 مرحله ششم: انتشار سایت در GitHub Pages

برای انتشار نسخه شخصی سایت خود:

1. وارد [GitHub](https://github.com/) شوید.
2. یک Repository جدید بسازید.
3. نام Repository را به شکل زیر انتخاب کنید:

```text
USERNAME.github.io
```

4. فایل‌های پروژه را در مخزن جدید قرار دهید.
5. وارد Settings شوید.
6. بخش Pages را باز کنید.
7. گزینه Deploy from a branch را انتخاب کنید.
8. شاخه `main` و پوشه `/ (root)` را انتخاب کنید.
9. روی Save کلیک کنید.

آدرس سایت شما:

```text
https://USERNAME.github.io
```

به‌جای `USERNAME` نام کاربری GitHub خودتان را قرار دهید.

## 🔐 آموزش پنل مدیریت | Admin Panel

این پروژه دارای رابط مدیریت برای کنترل اطلاعات پورتفولیو است.

**آدرس پنل مدیریت:**

نسخه آنلاین:

```text
https://parsa7400.github.io/?admin=1
```

نسخه محلی:

```text
http://localhost:5500/?admin=1
```

### 🔑 اتصال GitHub API

برای استفاده از قابلیت ذخیره‌سازی GitHub، باید احراز هویت API را پیکربندی کنید.

1. وارد GitHub شوید.
2. به Settings بروید.
3. Developer settings را باز کنید.
4. وارد Personal access tokens شوید.
5. Fine-grained tokens را انتخاب کنید.
6. یک توکن جدید بسازید.
7. فقط مخزن موردنیاز را انتخاب کنید.
8. دسترسی Contents موردنیاز را تنظیم کنید.

> ⚠️ **هشدار امنیتی:** توکن GitHub را داخل HTML یا JavaScript عمومی قرار ندهید. هر بازدیدکننده می‌تواند توکن موجود در کد فرانت‌اند را استخراج کند. برای محیط واقعی، درخواست‌های GitHub را از طریق Backend امن انجام دهید و توکن را فقط روی سرور نگه دارید.

## 🧰 مشکلات رایج | Troubleshooting

| مشکل | راه‌حل |
|:---|:---|
| سایت باز نمی‌شود | اجرای سرور و آدرس localhost را بررسی کنید. |
| اطلاعات نمایش داده نمی‌شوند | ساختار portfolio.json را بررسی کنید. |
| Git شناسایی نمی‌شود | Git را نصب و ترمینال را مجدداً باز کنید. |
| Live Server کار نمی‌کند | افزونه را نصب یا فعال کنید. |
| ذخیره GitHub ناموفق است | دسترسی API و احراز هویت را بررسی کنید. |
| تصاویر نمایش داده نمی‌شوند | لینک تصاویر را بررسی کنید. |
| تغییرات نمایش داده نمی‌شوند | صفحه را Refresh کنید و Cache را پاک کنید. |
