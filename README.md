## 🌟 درباره پروژه (About Project)

این پروژه یک **پورتفولیوی شخصی و مرکز توسعه فوق‌العاده مدرن، تعاملی و واکنش‌گرا** است که بر روی **GitHub Pages** میزبانی می‌شود. ویژگی کلیدی این سایت، داشتن یک **پنل مدیریت (Admin Panel) اختصاصی و امن** است که مستقیماً از طریق **GitHub Contents API** به مخزن متصل شده و به شما اجازه می‌دهد تمام اطلاعات سایت را بدون نیاز به کدهای پیچیده، به صورت زنده ویرایش، ذخیره و بروزرسانی کنید.

---

## 🚀 ویژگی‌های کلیدی (Key Features)

- **🔥 پنل ادمین یکپارچه و امن:** قابلیت مدیریت و ویرایش کامل محتوا (پروفایل، مهارت‌ها، پروژه‌ها، شبکه‌های اجتماعی و متن‌ها) و ذخیره مستقیم تغییرات در مخزن گیت‌هاب از طریق توکن شخصی (Fine-grained PAT).
- **📊 انیمیشن‌های پیشرفته (Count-up & Meter):** انیمیشن‌های روان شمارش اعداد و درصد مهارت‌ها همزمان با لود اسکرول صفحه (`IntersectionObserver`).
- **🧊 جلوه‌های بصری سه‌بعدی (3D Tilt Cards):** کارت‌های تعاملی با افکت‌های حرکتی جذاب و دکمه‌های موج‌دار (`Ripple Effects`).
- **🌐 پشتیبانی چندزبانه (i18n):** ساختار هوشمند برای مدیریت محتوای چندزبانه (فارسی و انگلیسی).
- **⚡ معماری سبک و سریع:** پیاده‌سازی شده با Vanilla JavaScript مدرن بدون نیاز به فریم‌ورک‌های سنگین سمت فرانت‌اند.

## 🛠️ تکنولوژی‌های استفاده شده (Tech Stack)

* **Frontend:** HTML5, CSS3, Modern ES6+ JavaScript
* **Data Layer:** Structured JSON (`portfolio.json`)
* **API & Auth:** GitHub REST API (Fine-grained Tokens with Contents Read/Write permissions)
* **Hosting:** GitHub Pages
